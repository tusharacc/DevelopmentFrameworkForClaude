# BUG-020 — code-quality sub-agents have no model assignment

**Severity:** Low
**Status:** Open
**Filed by:** Reviewer — assign-model-for-commands
**Date:** 2026-06-02

## Description
The three sub-agent prompt files in `skills/code-quality/agents/` (`simplify.md`, `secure-coding.md`, `secret-detection.md`) are plain markdown with no YAML frontmatter. They cannot hold a `model:` key in their current format and therefore inherit their model from the invoking context (currently the `observe` skill at `sonnet`).

## Impact
No immediate impact — `observe` (sonnet) is a reasonable default for quality analysis. However, if sub-agents are ever invoked independently or the `observe` skill model changes, these sub-agents have no explicit assignment.

## Suggested Fix
Convert `skills/code-quality/agents/*.md` to use YAML frontmatter (add `---` delimiters with a `model:` key) so each sub-agent can be independently controlled. Assign `model: sonnet` to all three.
